# Device Warden プライバシーポリシー

最終更新: 2026-11-28

Device Warden（以下「本アプリ」）は、Windows 向けの Android 端末リース管理ツールです。本ポリシーは、本アプリが扱う情報と、その取り扱いを説明します。

## 収集しない情報

本アプリは、開発者や第三者のサーバーへ利用状況・端末情報・個人情報を送信しません。アクセス解析、クラッシュレポートの自動送信、広告、利用者アカウントの仕組みはありません。

本アプリの API は `127.0.0.1`（localhost）でのみ待ち受け、トークン認証を必須にしています。外部から接続できる待ち受け口はありません。

## 端末内で扱う情報

本アプリは、端末のリース状態を管理するために次の情報を**利用者の PC 内だけ**に保存します。保存先は `DEVICE_WARDEN_HOME`（既定: `%USERPROFILE%\.device-warden`）です。

| 保存するもの | ファイル | 内容 |
| --- | --- | --- |
| リース DB | `warden.db` | Android 端末のシリアル・端末名・ブランド・接続状態、リース状態、所有者（人間 / AI ツール名）、AI のセッション ID・タイトル・プロジェクト名・作業ディレクトリ、確保・解放の履歴（監査ログ） |
| Broker トークン | `broker.token` | ローカル API の認証トークン。Broker の起動中だけ存在し、正常終了時に削除されます |
| アイコン | `device-warden.ico` | トレイとウィンドウの表示用に生成した画像 |

AI のリースには、利用者が使用中のツール名・セッション名・プロジェクト名・作業ディレクトリが記録されることがあります。これらは端末内の DB にのみ保存され、外部へ送信されません。共有 PC などで履歴を残したくない場合は、後述の方法で DB を削除してください。

## 外部との通信

- 本アプリ自身の通信は localhost の API のみです。
- 端末の操作には、利用者の PC にインストールされた `adb`（Android SDK Platform-Tools）と、任意で `scrcpy` をローカルに呼び出します。`adb` は端末との通信を `adb` の仕様に従って行いますが、開発者のサーバーへ情報を送ることはありません。
- **カタログ機能（Obtainium 連携）を使った場合に限り**、GitHub の公開リリース情報を取得するため `gh`（GitHub CLI）を呼び出します。送信されるのはリポジトリ名などの一般的なリクエストで、端末情報・リース情報・個人情報は含みません。認証は利用者の `gh` の設定に従います。この機能を使わなければ、外部への通信は発生しません。

## 第三者提供

本アプリは、利用者の情報を第三者へ提供・販売しません。広告目的の送信も行いません。

## 保存した情報の削除

`%USERPROFILE%\.device-warden` フォルダを削除すると、リース DB・トークン・アイコンが消えます。アンインストールしてもこのフォルダは自動では削除されないため、必要に応じて手動で削除してください。削除した情報は復元できません。
