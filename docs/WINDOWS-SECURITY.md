# Windowsのローカルデータと権限

Device Wardenは同一PC内の協調ツールであり、同じユーザーのプロセスや管理者からの隔離境界ではありません。Brokerトークン、SQLite DB、バックアップには端末シリアル、ローカルパス、セッション情報などが含まれ得ます。公開・共有しないでください。

## 保存先とACL

既定の保存先は `%USERPROFILE%\.device-warden` です。`DEVICE_WARDEN_HOME` を指定すると別の場所を使います。新規作成時のアクセス権は親フォルダから継承されるため、**保存場所とWindowsの設定に依存**します。Pythonの `chmod` はWindowsのACLを十分に制御しません。移動先が共有フォルダ、別ユーザーが読める場所、バックアップ同期対象の場合は特に注意してください。

確認例（自身の環境で実行。結果にはユーザー名やローカルパスが含まれるため公開しないこと）:

```powershell
icacls "$env:USERPROFILE\.device-warden"
# DEVICE_WARDEN_HOME を設定している場合
icacls "$env:DEVICE_WARDEN_HOME"
```

フォルダだけでなく `broker.token`、`warden.db`、SQLiteの一時ファイルやバックアップも確認してください。別ユーザーへアクセスを許すエントリがある場合は、そのWindows環境の管理者に相談してください。既存のACLをアプリが自動変更すると、利用者やバックアップのアクセスを壊す恐れがあるため、現時点では変更しません。

## 検証状況

開発環境の既定フォルダではSYSTEM、Administrators、現在のユーザーへの継承されたフルコントロールを確認しました。これは**その環境だけの結果**であり、別のユーザーでの実読み取り試験や、任意の `DEVICE_WARDEN_HOME` に対する検証は未実施です。トークン認証はlocalhostへのアクセス制御であり、トークンやDBを読める同一ユーザーのプロセスからの保護ではありません。
